完井方式智能优选 —— 案例包说明
=====================================================
适用场景：ATLAS 站点第七部分「完井」中的 C01 场景（sceneId = co1）
方法标签：KG 知识图谱 + CBR 案例推理｜难度：中

这是什么
-----------------------------------------------------
完井是「井打完之后怎么把地层和井筒接起来」：裸眼、射孔、筛管、砾石充填
四种方式，选哪一种取决于地层出不出砂、离底水多远、渗透率与厚度。麻烦在于：

  · 决策窗口只有 1–3 天，而选错的代价要 12–24 个月后才暴露（出砂大修、
    含水上升），那时候已经改不动了；
  · 真正的依据藏在邻井的完井总结与投产表现里，靠人翻资料要几天；
  · 老专家退休后，同样的决策要重新说服一遍。

智能化介入的是「找邻井」这一步：知识图谱先按层系、岩性、年代把检索范围
收紧，案例推理再在里面做加权近邻投票。它输出的是候选排序 + 证据清单，
不是拍板——裁定权与责任仍然在人手里。

怎么用
-----------------------------------------------------
1. 打开站点 index.html，右上角「＋ 添加案例」
2. 把整个 completion-mode-reco 文件夹拖进上传区
3. 校验全绿后点「校验并添加」

也可以直接打开 demo/index.html 单独看示范。

-----------------------------------------------------

                       井筒剖面 + 代价滞后时间轴 / 知识图谱 + 案例推理两层 /
                       数据分层与口径 / 量纲、样本不平衡、带宽 σ 三个坑）

示范里有什么
-----------------------------------------------------
  · 第一张图（候选排序）：四种完井方式的加权票数条，条上标出「几口井投了
    票 / 投了多少票」，右侧是置信度与次优候选；
  · 第二张图（相似度分布）：32 口邻井按相似度从高到低排成条形，实色是进入
    票池的前 K 口，虚线是 K 的切分位置，红色横线是「还算像」的下限——
    在 K 处断崖式下跌说明前 K 口本来就是自然的一组，平缓滑落则说明
    第 K 口与第 K+1 口其实差不多，K 取多少都带偶然性；
  · 第三张图（特征画像）：四个特征各一行，灰色带是邻井分布范围、圆点是
    加权均值、竖线是待钻井，右侧是该特征在相似度里的权重。竖线落在灰带
    中段才算真的像；
  · 表格列出参与投票的证据井（条件、采用方式、投产后比采油指数），
    票数从哪来是看得见的。

想看出东西，可以按下面的顺序拖
-----------------------------------------------------
  1. 出砂指数拉到 0.7 以上 → 砾石充填票压倒性领先；
  2. 出砂指数很低、距底水拉远 → 裸眼完井上位；
  3. 把 K 调大到 15 → 不相似的井被拉进票池，置信度下降，推荐变犹豫；
  4. 条件设到样本稀疏区（低出砂 + 极近距离水）→ 出现「样本不足」提示，
     这正是第 5 步「人工裁定与回填」存在的理由：模型该知道自己不知道；
  5. 对照第二、三张图看：总相似度不低，但竖线落在灰带边缘——
     说明它是被其它特征「拉」进票池的，不是真的像。

免责说明
-----------------------------------------------------
示范用的是为演示生成的 32 口虚拟邻井，相似度权重、高斯核带宽、置信度阈值
与「35% 像的下限」均为演示取值，未经现场标定。可用于说明方法流程与
「证据可追溯」带来的差别，不可用于完井方式选型与方案报批。

完井方式智能优选 · 相似案例检索

一口新井要选完井方式（裸眼 / 射孔 / 筛管 / 砾石充填），最可靠的依据是「地质条件相近的老井当年怎么选、后来产得怎么样」。 这里把 32 口邻井的「储层特征—完井方式—产能表现」组织成案例库，按加权相似度挑出最像的几口，用它们的投票给出候选排序。 拖动滑杆改变待钻井的条件，看推荐怎么变、什么时候变成「样本不足」。

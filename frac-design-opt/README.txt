储层压裂增产智能方案设计（完井配套压裂）—— 案例包说明
=====================================================
适用场景：ATLAS 站点第七部分「完井」中的 C07 场景（sceneId = co7）
方法标签：OPT 优化算法（代理模型 + 硬约束寻优 + 闭环调参）｜难度：高

这是什么
-----------------------------------------------------
压裂是把岩石压出缝、再用支撑剂撑住不让它闭合。三个设计参数互相牵制：

  · 簇间距 → 簇数与簇间竞争：间距小则覆盖好，但单缝变窄；
  · 排量 → 缝高与施工压力：排量大则缝高易穿层、压力可能超限；
  · 加砂程序 → 导流能力：砂比过高会砂堵，过低则导流不足。

所以不存在「排量越大越好」，每个参数都有它自己的上限来源。工程上的障碍是
缝模跑一次要 20–40 分钟，无法穷举——所以先用缝模批量生成样本训练毫秒级
代理模型，再在代理模型上做硬约束剪枝与多目标寻优。

两条纪律要写进流程：硬约束必须前置（违规组合不该出现在推荐列表里，否则
工程师手动返工后就不再相信输出）；多目标不要加权成标量（权重是人拍的，
油价一变结论就作废，出前沿才能保留合法选择）。施工阶段的闭环调参必须有
护栏——单次幅度上限、硬约束实时复校、异常回退 + 人工确认。

怎么用
-----------------------------------------------------
1. 打开站点 index.html，右上角「＋ 添加案例」
2. 把整个 frac-design-opt 文件夹拖进上传区
3. 校验全绿后点「校验并添加」

也可以直接打开 demo/index.html 单独看示范。

示范里有什么
-----------------------------------------------------
  · 第一张图（裂缝形态）：单段裂缝的半长、缝高与层位关系，标出是否穿层；
  · 第二张图（泵注程序）：砂比与施工压力随泵注时间的变化，以及限压线，
    能看出砂堵与压力超限发生在哪一段；
  · 第三张图（成本—EUR 前沿）：候选方案散点与前沿曲线，红虚线是成本上限，
    绿圈是预算内最优；
  · 读数给出 EUR 相对指数、单井成本、三条硬约束的校核结果与最优组合。

想看出东西，可以按下面的顺序拖
-----------------------------------------------------
  1. 默认（间距 12 m / 排量 14 / 加砂 60 t / 前置液 50%）→ EUR 93、
     成本 699 万，预算内最优是间距 8 m / 排量 10（EUR 111、成本 696 万）：
     同样的钱还能多拿 18 个点；
  2. 把排量拉到上限 → 缝高穿层、施工压力超限，方案被硬约束剪掉；
  3. 把加砂强度拉到上限 → 砂比越出携砂窗口，出现砂堵提示；
  4. 把成本上限收紧 → 前沿与预算线的交点左移，所选方案改变；
  5. 切换到闭环模式 → 看单次调整幅度上限与人工确认如何限制模型输出。
  6. 注意：最优解不一定排量最大、加砂最多——三条硬约束已经把搜索空间
     切掉了一大块，剩下的才是能施工的区域。

免责说明
-----------------------------------------------------
示范用的是降阶裂缝与 EUR 模型，地应力、缝高、EUR 与成本均为演示取值，
未经现场标定，EUR 为相对指数而非产量预测。可用于说明「代理模型 + 硬约束
前置 + 前沿寻优 + 闭环护栏」的流程，不可用于压裂方案设计与报批。

完井井筒腐蚀与结垢智能预测及防护方案推荐 —— 案例包说明
=====================================================
适用场景：ATLAS 站点第七部分「完井」中的 C10 场景（sceneId = co10）
方法标签：OPT 优化算法（内部以机理关系式 + 代理为前提）｜难度：中

这是什么
-----------------------------------------------------
腐蚀与结垢是同一套流体化学的两面，但它们沿井筒深度并不均匀：

  · 腐蚀速率主要跟着温度走 —— 井底最重
  · 碳酸钙结垢主要由压力释放引起 —— 浅处更重
  · 两者的峰值通常不在同一深度，工况一变位置还会移动

智能化介入三步：沿深度把两条速率曲线算出来并定位控制段；把「管材 × 缓蚀剂
× 阻垢剂」的组合空间摊开（924 组）；把管材摊销、药剂费与检测费统一到年化
成本这一个口径上再选。

怎么用
-----------------------------------------------------
1. 打开站点 index.html，右上角「＋ 添加案例」
2. 把整个 corrosion-scale-protect 文件夹拖进上传区
3. 校验全绿后点「校验并添加」

也可以直接打开 demo/index.html 单独看示范。

示范里有什么
-----------------------------------------------------
  · 沿深度（61 个节点）计算温度压力剖面，用 de Waard 型关系式给出 CO₂ 腐蚀速率
    （高温高分压区做了限幅并注明失真），用「压力释放 + 温度 + 钙硬度」给出结垢指数；
  · 防护方案 = 管材（碳钢 J55 / 3Cr / 13Cr / 22Cr 双相）× 缓蚀剂（0–200 ppm）
    × 阻垢剂（0–50 ppm）＝ 924 组；
  · 两条硬约束：硫化氢超抗硫边界直接否决、超软边界寿命按 0.7 折算；剩余寿命
    必须 ≥ 设计年限 10 年；
  · 成本 = 管材摊销（一次性 / 寿命）+ 药剂费（年年付）+ 检测费，统一到年化口径；
  · 与「常用做法」（碳钢 + 缓蚀剂 100 ppm + 阻垢剂 15 ppm）对比。

想看出东西，可以按下面的顺序拖
-----------------------------------------------------
  1. 默认工况（CO₂ 0.30 MPa、H₂S 50 ppm、Cl 40000、95 ℃、22 MPa、150 m³/d）：
     腐蚀峰值在井底、结垢峰值在井口，两条曲线交叉；推荐 22Cr 双相 + 缓蚀剂
     110 ppm，比常用做法（寿命只有 1.1 年）明显更省——<b>贵的管材更省</b>；
  2. 把 CO₂ 降到 0.05、温度降到 60：推荐变成 13Cr 且缓蚀剂为 0 ppm——温和工况下
     「不加药」才是最优点，加药是纯支出；
  3. 把 H₂S 拖到 300 ppm：碳钢与 13Cr 因超过抗硫硬边界被否决，只剩 22Cr 双相，
     且提示寿命已按 0.7 折算（抗硫是材料硬约束，加药补不回来）；
  4. 看第三张图的 U 形曲线：缓蚀剂浓度从 0 加到最优点是省钱，再往上加就是白付；
  5. 把矿化度与温度同时拉到高位：可能没有任何组合满足设计年限，此时界面会
     如实报告「无满足设计年限的组合」，而不是硬凑一个。

免责说明
-----------------------------------------------------
示范用的是为演示而写的降阶模型：腐蚀与结垢为经验关系式（高温高分压区已限幅
并标注失真），价格、寿命阈值与药剂效率均为演示取值。可用于说明方法流程与
「先定位、再寻优、统一成本口径」带来的差别，不可用于选材、加药与寿命评估。

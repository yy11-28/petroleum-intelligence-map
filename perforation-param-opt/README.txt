射孔参数智能设计 —— 案例包说明
=====================================================
适用场景：ATLAS 站点第七部分「完井」中的 C02 场景（sceneId = co2）
方法标签：OPT 优化算法（代理模型寻优）｜难度：中

这是什么
-----------------------------------------------------
射孔是在套管上打出通道，让地层里的油气进井筒。三个参数可以调：
孔密（每米几孔）、相位（孔眼在圆周上的排布）、穿深（打进地层多深）。
难在两个目标方向相反：

  · 孔打得密、打得深 → 流动通道多 → 产能高；
  · 但同时孔眼周围应力集中更强 → 更容易出砂。

所以不存在「最好的一组参数」，只有在给定出砂容忍度下产能最高的那一组。
另一个现实约束：机理模型跑一次要 30–60 分钟，穷举几万组根本不可能——
所以需要先用实验设计采样几百组训练一个毫秒级的代理模型，再在代理模型上
做穷举寻优。代理模型不是「换个算法猜」，而是把机理模型的计算成本摊掉。

怎么用
-----------------------------------------------------
1. 打开站点 index.html，右上角「＋ 添加案例」
2. 把整个 perforation-param-opt 文件夹拖进上传区
3. 校验全绿后点「校验并添加」

也可以直接打开 demo/index.html 单独看示范。

示范里有什么
-----------------------------------------------------
  · 第一张图（帕累托前沿）：产能比—出砂风险的散点与前沿曲线，绿色为可行、
    灰色为不可行，横虚线是出砂容忍上限，星号是约束下的最优；
  · 第二张图（单参数灵敏度）：孔密、相位、穿深各一张小图，实线是产能比、
    橙虚线是出砂风险，竖线是当前取值。曲线的斜率就是「这个参数还值不值得
    调」——平缓段再怎么调也拿不到产能，陡峭段一两个步长就有差别；
  · 第三张图（表皮分解）：三个方案（标准 / 当前 / 约束下最优）的表皮构成，
    橙色是钻井损害表皮（固定、为正），彩色是射孔表皮（可调、通常为负）。
    射孔做得好，表皮可以是负的，等于把钻井时的损害补偿回来；
  · 读数给出产能比、相对标准方案的提升、出砂风险、约束判定与最优组合。

想看出东西，可以按下面的顺序拖
-----------------------------------------------------
  1. 默认工况 → 产能比 0.716，比标准方案高 4.8%，约束下最优还能再拿 33%；
  2. 把孔密一路拉大 → 产能上去，但橙虚线越过红横线，可行域开始被切；
  3. 岩石强度（UCS）调低 → 同一组参数的出砂风险整体抬升，最优组合会
     自动往孔密小、穿深浅的方向退；
  4. 把出砂容忍度收紧 → 可行集变空，界面会如实报告「无可行组合」而不是
     硬凑一个答案；
  5. 对照第二张图：找出当前工况下斜率最陡的那个参数，它就是最值得谈的
     一项。

免责说明
-----------------------------------------------------
示范用的是降阶射孔表皮模型与演示取值的出砂判据，代理模型为现场计算的
简化替身，未做实验标定。可用于说明「代理模型 + 约束寻优」的流程与
前沿/约束的关系，不可用于射孔参数设计与作业决策。

完井管柱受力智能分析 —— 案例包说明
=====================================================
适用场景：ATLAS 站点第七部分「完井」中的 C03 场景（sceneId = co3）
方法标签：OPT 优化算法（代理模型 + 蒙特卡洛）｜难度：中

这是什么
-----------------------------------------------------
管柱下井后并不是静止的。投产时的三个效应会叠加成封隔器处的真实轴力：

  · 浮重（自重 − 浮力）→ 拉伸；
  · 活塞效应（井筒内降压）→ 拉伸；
  · 温度效应（升温被封隔器约束住）→ 压缩。

三者相加才是真实轴力，只算自重会差出一个量级。对应的两种失效形式判据
完全不同：拉断看「井口拉力 vs 接头强度」，屈曲看「压缩段 vs 正弦/螺旋
屈曲临界载荷」。难点在于——这两个安全系数常常被同一个参数往相反方向推：
提高生产压差会让拉伸变差、屈曲变好。只看一头必然漏掉另一头。

智能化介入的是「工况太多，人只能校核几格」：代理模型把几万组工况全扫一遍，
把危险区的边界画出来，再对参数区间做蒙特卡洛抽样给出失效概率。

怎么用
-----------------------------------------------------
1. 打开站点 index.html，右上角「＋ 添加案例」
2. 把整个 completion-string-force 文件夹拖进上传区
3. 校验全绿后点「校验并添加」

也可以直接打开 demo/index.html 单独看示范。

示范里有什么
-----------------------------------------------------
  · 第一张图（危险区分布）：整个工况空间（压差 × 温升）的安全系数色阶图，
    色阶固定（<1 红 / 1–1.3 橙 / 1.3–1.8 米 / >1.8 绿），圆圈是当前工况，
    下方标出危险区占比与代理模型的查全率；
  · 第二张图（轴向力构成）：封隔器处浮重 / 活塞效应 / 温度效应三段的堆叠
    与抵消，直接看出「力从哪来」；
  · 第三张图（拉—压对抗）：左图扫温升、右图扫压差，各画拉伸安全系数与
    屈曲安全系数两条曲线。两条线的交点就是设计的真正控制点：交点左侧受
    拉伸控制、右侧受屈曲控制。注意左图——温升对拉伸几乎没影响，却会持续
    把屈曲安全系数压下去，只看井口拉力是看不出这一段的；
  · 读数给出井口拉力、两个安全系数、屈曲判定与代理模型查全率。

想看出东西，可以按下面的顺序拖
-----------------------------------------------------
  1. 默认工况 → 拉伸安全系数 1.68、未屈曲，但整个空间里有 5.9% 的组合
     不安全：你校核的那一格是好的，没校核的那一格才是出事的；
  2. 把温差拉大 → 屈曲安全系数掉下去，而拉伸几乎不变（看第三张左图）；
  3. 把压差拉大 → 反过来，拉伸变差、屈曲变好（看第三张右图）；
  4. 切换封隔器锚定方式 → 温度效应被释放或约束，压缩段整体改号；
  5. 对照第一张图：把当前工况拖到红色区边缘，看代理模型是否也判为危险
     ——查全率 85.7% 意味着临界附近确实会漏判，这正是流程里要单独统计
     危险区查全率的原因。

免责说明
-----------------------------------------------------

一趟作业会产生上万条秒级时序。传统做法给每个参数设一个越限阈值——正常工序切换也会报警（误报），而「泵压缓慢升＋排量缓慢降」的复合前兆两个参数都没超限（漏报）。拖动异常演化速度，对比两种模式的报警表现。

一趟完井作业的时序与报警标记（大钩载荷 / 泵压 / 排量）

人工做法 vs 模型做法（同一口井，同一批数据）
人工做法（现状）
  • 固定阈值报警，工况切换满屏误报
  • 异常要人工翻历史曲线比对
  • 处置经验靠人口传，不沉淀
模型做法（本示范）
  • 先分工况再判异常，误报率 62% → 14%
  • 报警自带偏离度、持续时长与历史相似案例
  • 处置结论回填样本库，复现性异常沉淀成规则
